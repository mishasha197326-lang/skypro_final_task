Git - всему голова!

  • git init — инициализирует новый репозиторий в текущей директории, создавая скрытую папку.
  • git clone "URL_репозитория" — клонирует существующий репозиторий.
  • git status — показывает текущее состояние файлов в рабочем каталоге: неотслеживаемые, изменённые и подготовленные к коммиту файлы.
  • git commit — фиксирует изменения в репозитории.
  • git push — отправляет изменения в удалённый репозиторий.
  • git pull — получает последние изменения из удалённого репозитория и обновляет локальный проект.
